# Domain notes (FreshCart Online)
- "Something missing", "items damaged", "wrong item", "substitution I didn't want", "money back" → an issue with the items (`items_issue` true).
- `wants_link`: true for "yes, text it to me", "send me the link"; false for "no thanks" or "I'll do it myself".
- `wants_agent` only true when they clearly ask for a person, colleague or someone to talk to.
- "That's everything, thanks" → `anything_else` false.
